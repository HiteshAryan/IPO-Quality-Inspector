# IPO-Quality-Inspector
Gamified pre-IPO financial quality scoring platform: a four-dimension framework (revenue, earnings &amp; cash flow, balance sheet, governance) for reading a prospectus like a detective - backtested on six landmark IPOs: WeWork 26/100, Ola Electric 32, Paytm 43, Zomato 67, Jio 69, Alibaba 81.
